# Hero background

Upload one of the following for the homepage's full-screen hero background:

```
hero.mp4  or  hero.webm     ← video, takes priority if both a video and image are uploaded
hero.webp / hero.jpg / hero.png     ← image
```

**Recommended**
- Landscape orientation, at least 2400 x 1350px for the still image.
- If uploading video: keep it under ~15MB and 10-20 seconds long. No audio
  needed, it plays muted and loops automatically. Upload `hero.jpg` too if
  you can, it's used as the poster frame while the video loads.
- The site overlays a soft dark gradient on top of whatever you upload so
  the heading text stays readable, so slightly brighter, airy shots or
  footage tend to read best.
