# Services photos

One photo per service, named exactly as shown (`.webp`, `.jpg`, or `.png`).
Landscape orientation recommended (roughly 4:3).

```
event-styling.jpg
backdrops.jpg
full-decor-packages.jpg
```

These appear on the Services page next to each service's description.
`full-decor-packages.jpg` is used as a full-width background banner, so a
photo with some open, less-busy space works especially well there.
