# Logo

Upload your logo **mark** (the icon/monogram symbol alone, not the full text
lockup) as one of:

```
mark.svg     ← preferred, if you have a vector file
mark.webp
mark.png
mark.jpg
```

This one file is used everywhere the mark appears: the nav bar, the footer,
the browser tab icon, the mobile "add to home screen" icon, and the preview
image shown when the site is shared on social media.

**Tips**
- Square or near-square works best, it's displayed in a small circle/box.
- A transparent background (SVG or PNG) looks best, since it sits on both
  the ivory and charcoal backgrounds used across the site.
- Don't include the "Dream Decor" text in this file, the script wordmark
  next to it is generated by the site itself. Just upload the icon/mark.
